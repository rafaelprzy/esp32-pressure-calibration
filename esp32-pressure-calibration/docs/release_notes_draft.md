# Proposed release v1.0.0

Label: Educational experimental prototype

This proposed first release packages the completed ESP32-S3/HX710B low-pressure calibration experiment: fourteen unchanged raw datasets, portable base-R analysis, six original and six regenerated scientific figures, sanitized final firmware, a technical report and reproduction instructions.

Calibration uses six P0-P5 means; P6 is held out. Fit RMSE is 0.01139345 kPa and R squared is 0.995101539 over -0.02941995 to +0.44129925 kPa. Later positive-pressure validation RMSE is 0.00897939 kPa, conditional on V3's assigned reference despite its missing final height. Four zero means span 0.07064438 kPa. These are experimental results, not certified accuracy claims.

The package is unsuitable for clinical, patient-monitoring or safety-critical use. The proposed release has not been published, tagged or uploaded. No release date or DOI is claimed.
